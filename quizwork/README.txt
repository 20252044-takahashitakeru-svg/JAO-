# 脳トレ！早押しクイズ - ローカル対戦版

## 必要な環境
PHPが動くPC（XAMPP / MAMP / PHP内蔵サーバーなど）と、同じLAN/Wi-Fiに接続した参加者の端末。

## 起動方法（PHP内蔵サーバー）
1. このフォルダをPCに展開。
2. ターミナルでこのフォルダを開く。
3. `php -S 0.0.0.0:8000` を実行。
4. PCでは `http://localhost:8000/` を開く。
5. 他の端末では、ホストPCのローカルIPを使って `http://192.168.x.x:8000/` のようにアクセスする。
6. 1人が「部屋を作る」を押し、表示された6文字の合言葉を他の参加者に伝える。
7. 全員が名前と合言葉を入力して「参加する」。ランキングは約1秒ごとに更新される。

## 注意
- `data` フォルダに部屋情報がJSONで保存されます。
- インターネット上へ公開する用途ではなく、同じローカルネットワーク内での展示・対戦を想定しています。
- Windowsファイアウォールが8000番ポートへの接続をブロックする場合があります。その場合はPHP/8000番ポートの通信を許可してください。
